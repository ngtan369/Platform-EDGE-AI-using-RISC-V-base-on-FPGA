# Heterogeneous Edge-AI Acceleration Platform — Kria KV260

[![Hardware](https://img.shields.io/badge/Hardware-Kria_KV260-orange.svg)]()
[![Core](https://img.shields.io/badge/RISC--V-CV32E40P-blue.svg)]()
[![AI Framework](https://img.shields.io/badge/AI-TensorFlow_Lite-yellow.svg)]()
[![Status](https://img.shields.io/badge/Status-Ongoing-success.svg)]()

INT8-quantized CNN inference across two compute cores on Xilinx Kria KV260 (`xck26-sfvc784-2LV-c`): an ARM Cortex-A53 host (PYNQ/Linux) orchestrates a CV32E40P RISC-V soft-core that drives a custom 3×3 conv accelerator in the FPGA fabric. Currently supports binary classification (INRIA person detection, Cats vs. Dogs) using the `vgg-tiny` model.

---

## Repository structure

```
hw/                 # FPGA hardware
├── rtl/            # SystemVerilog: riscv_top.sv, obi_to_axi.sv
├── cv32e40p/       # Git submodule — OpenHW RV32IMC core
├── ip_repo/        # conv_cnn_1_0 (accelerator), riscv_top_1_0 (wrapper)
├── vivado_pj/      # Vivado block-design project (.xpr)
└── artifacts/      # kria_soc_wrapper.bit + .xsa (tracked)

firmware/           # Bare-metal RISC-V (CV32E40P, no OS)
├── main.c          # Layer-by-layer DMA driver
├── layer_table.h   # AUTO-GENERATED by training/train.ipynb
├── linked.ld       # IRAM @ 0x0000_0000 / DRAM @ 0xB004_0000
└── Makefile        # riscv-none-elf-gcc -march=rv32imc -mabi=ilp32

host/               # PYNQ runtime on KV260 ARM
├── edge_ai/        # Python package (overlay, preprocess, postprocess)
├── notebooks/      # inference_demo.ipynb, benchmark.ipynb
└── scripts/        # deploy.sh, infer.py

training/           # PC-side: model training + PTQ + artifact emit
├── edge_train/     # Python package (models, quantize, emit)
└── train.ipynb     # Single entry point (Colab or local)

docs/               # memory-map.md, report PDF, schematics
```

## Quick start

### 1. Train & emit

```bash
# Open training/train.ipynb, set MODEL=vgg-tiny, DATASET=inria or cats_dogs, Run All
# Outputs: training/export/*.bin + firmware/layer_table.h
```

### 2. Build firmware

```bash
make -C firmware
# requires riscv-none-elf-gcc; re-run after every training run
```

### 3. Build bitstream

Open `hw/vivado_pj/vivado_pj.xpr` in Vivado → Generate Bitstream → export `.bit` + `.xsa` to `hw/artifacts/`.

### 4. Deploy to board

```bash
# One-time board prep:
ssh ubuntu@kv260.local 'sudo mkdir -p /home/ubuntu/edgeai && sudo chown ubuntu:ubuntu /home/ubuntu/edgeai'

# Deploy:
bash host/scripts/deploy.sh
```

### 5. Run inference (Jupyter)

```bash
ssh ubuntu@kv260.local
sudo -E env "PATH=$PATH" jupyter notebook --no-browser --ip=0.0.0.0 --port=9090
# Open http://kv260.local:9090 → notebooks/inference_demo.ipynb
```

## Architecture

```
ARM (PYNQ)  ──► preprocess image ──► write shared regs (D-BRAM Port B @ 0xB004_0000)
                                       ──► CMD_START
CV32E40P    ──► reads LAYERS[] ──► programs AXI-DMA + conv_cnn per layer ──► STATUS_DONE
ARM         ──► reads OFM from DDR ──► GAP + softmax + argmax ──► label + confidence
```

Memory map: see [docs/memory-map.md](docs/memory-map.md).
